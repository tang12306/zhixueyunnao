# 系统连接问题解决方案

> 历史记录：文中的 Node.js 后端（端口 5000）和 `VUE_APP_NODE_API_URL` 已下线删除，现在前端只连接 Spring Boot。当前启动方式见根目录 README.md。

## 问题描述

用户反馈运行一键启动后前端无法连接到数据库的问题。

## 问题根源分析

### 1. 系统架构理解错误

**错误理解**：前端直接连接数据库
**正确理解**：前端通过后端API连接数据库

```
前端 (Vue.js) → 后端API (Spring Boot) → 数据库 (MySQL)
     8084端口        8080端口           3306端口
```

### 2. 多后端系统混淆

项目中存在两套后端系统：

1. **Node.js后端** (端口5000) - 旧系统，基本不使用
2. **Java Spring Boot后端** (端口8080) - 主要系统，处理所有业务逻辑

### 3. 端口冲突问题

- 一键启动脚本启动了多个服务
- 8080端口被占用导致Java后端无法启动
- 前端配置的端口不一致

### 2. 端口冲突解决

如果遇到端口占用问题：

```bash
# 查看占用8080端口的进程
netstat -ano | findstr :8080

# 杀掉占用端口的进程（替换PID为实际进程ID）
taskkill /PID <进程ID> /F
```

### 3. 前端API配置

前端有两套API配置：

#### Node.js API (基本不使用)
```javascript
const nodeApi = axios.create({
  baseURL: process.env.VUE_APP_NODE_API_URL || 'http://localhost:5000/api',
  timeout: 10000
});
```

#### Java API (主要使用)
```javascript
const javaApi = axios.create({
  baseURL: process.env.VUE_APP_JAVA_API_URL || 'http://localhost:8080',
  timeout: 180000,
  withCredentials: true
});
```

### 4. 环境变量配置

可以通过环境变量配置API地址：
- `VUE_APP_JAVA_API_URL`: Java后端API地址 (默认: http://localhost:8080)
- `VUE_APP_NODE_API_URL`: Node.js后端API地址 (默认: http://localhost:5000/api)

## 常见问题排查

### 1. 前端无法访问后端API

**症状**: 前端页面加载但API调用失败
**检查步骤**:
1. 确认Java后端是否启动 (http://localhost:8080)
2. 检查浏览器控制台是否有CORS错误
3. 验证API路径是否正确

**解决方案**:
```bash

```

### 2. 数据库连接失败

**症状**: 后端启动时报数据库连接错误
**检查步骤**:
1. 确认MySQL服务是否启动
2. 检查数据库配置 (application.properties)
3. 验证数据库用户权限

**解决方案**:
```sql
-- 检查数据库是否存在
SHOW DATABASES LIKE 'jiaowu_tiku';

-- 检查用户权限
SHOW GRANTS FOR 'root'@'localhost';
```

### 3. 端口冲突

**症状**: 启动时提示端口被占用
**解决方案**:
```bash
# 查找占用进程
netstat -ano | findstr :8080

# 终止进程
taskkill /PID <进程ID> /F
```
