# 超时问题修复说明

## 问题描述

在使用AI一键出卷功能时，遇到以下超时错误：

```
生成失败

生成试卷过程中出现错误，请稍后重试。 错误信息: timeout of 60000ms exceeded (注意：系统不再使用模拟数据填充试卷)
```

## 问题根源

AI生成试卷内容需要调用DeepSeek API，这个过程可能需要较长时间（通常1-3分钟），但系统的超时设置只有60秒，导致请求在AI还未完成生成时就被中断。

### 超时设置分析

**修复前的超时配置**：
1. **后端RestTemplate**：60秒
2. **前端javaApi**：60秒  
3. **前端AI出卷页面**：60秒

**问题**：AI生成复杂试卷内容通常需要1-3分钟，60秒的超时设置过短。

## 修复方案

### 1. 后端超时配置修复

**文件**：`src/main/java/com/_1/config/RestTemplateConfig.java`

**修复前**：
```java
RequestConfig requestConfig = RequestConfig.custom()
        .setConnectTimeout(Timeout.ofMilliseconds(60000))      // 连接超时60秒
        .setConnectionRequestTimeout(Timeout.ofMilliseconds(60000)) // 连接请求超时60秒
        .setResponseTimeout(Timeout.ofMilliseconds(60000))     // 响应超时60秒
        .build();
```

**修复后**：
```java
RequestConfig requestConfig = RequestConfig.custom()
        .setConnectTimeout(Timeout.ofMilliseconds(30000))      // 连接超时30秒
        .setConnectionRequestTimeout(Timeout.ofMilliseconds(30000)) // 连接请求超时30秒
        .setResponseTimeout(Timeout.ofMilliseconds(180000))    // 响应超时3分钟
        .build();
```

### 2. 前端API配置修复

**文件**：`frontend/src/api/index.js`

**修复前**：
```javascript
const javaApi = axios.create({
  baseURL: process.env.VUE_APP_JAVA_API_URL || 'http://localhost:8080',
  timeout: 60000, // 增加到60秒
  withCredentials: true
});
```

**修复后**：
```javascript
const javaApi = axios.create({
  baseURL: process.env.VUE_APP_JAVA_API_URL || 'http://localhost:8080',
  timeout: 180000, // 增加到3分钟，匹配后端设置
  withCredentials: true
});
```

### 3. 前端AI出卷页面修复

**文件**：`frontend/src/views/auto-quiz/AIExamGeneration.vue`

**修复前**：
```javascript
const response = await axios.post('/api/ai/generate-exam', requestData, {
  baseURL: process.env.VUE_APP_JAVA_API_URL || 'http://localhost:8080',
  withCredentials: true,
  timeout: 60000 // 增加超时时间到60秒
});
```

**修复后**：
```javascript
const response = await axios.post('/api/ai/generate-exam', requestData, {
  baseURL: process.env.VUE_APP_JAVA_API_URL || 'http://localhost:8080',
  withCredentials: true,
  timeout: 180000 // 增加超时时间到3分钟，匹配后端设置
});
```

## 技术细节

### 超时类型说明

1. **连接超时（Connect Timeout）**：30秒
   - 建立TCP连接的最大等待时间
   - 30秒足够建立网络连接

2. **连接请求超时（Connection Request Timeout）**：30秒
   - 从连接池获取连接的最大等待时间
   - 30秒足够获取连接

3. **响应超时（Response Timeout）**：180秒（3分钟）
   - 等待服务器响应的最大时间
   - 3分钟足够AI完成内容生成

### 为什么选择3分钟

1. **AI生成时间**：根据测试，复杂试卷生成通常需要1-2分钟
2. **网络延迟**：考虑网络波动和API响应延迟
3. **用户体验**：3分钟是用户可以接受的等待时间
4. **系统稳定性**：避免过长的超时导致资源占用
