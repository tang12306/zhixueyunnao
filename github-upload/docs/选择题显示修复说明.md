# 选择题显示修复说明

## 问题描述

在AI一键出卷功能中，生成的选择题只显示点号（•），没有显示具体的选项内容，如：

```
9. (3分) C++中，用于循环的关键字不包括？
•
•
•
•
```

## 问题根源

### 1. 数据结构不匹配

**后端数据结构**：
- Question实体类中的options字段是 `List<String>`
- DeepSeekService将AI返回的选项转换为字符串列表，格式为："A. 选项内容"

**前端期望结构**：
- 前端模板期望的是对象数组，包含 `key` 和 `content` 属性
- 原始代码：`{{ option.key }}. {{ option.content }}`

### 2. 题目类型不一致

**前端配置**：
- 使用 `FILL_BLANK` 作为填空题类型

**后端枚举**：
- 使用 `FILL_IN_THE_BLANK` 作为填空题类型

## 修复方案

### 1. 修复选择题选项显示

**修复前**：
```vue
<div v-for="option in question.options" :key="option.id" class="preview-option">
  {{ option.key }}. {{ option.content }}
</div>
```

**修复后**：
```vue
<div v-for="(option, optionIndex) in question.options" :key="optionIndex" class="preview-option">
  {{ option }}
</div>
```

### 2. 统一题目类型枚举

**修复的文件**：`frontend/src/views/auto-quiz/AIExamGeneration.vue`

**修复内容**：
- 题型列表：`FILL_BLANK` → `FILL_IN_THE_BLANK`
- 题目计划：`FILL_BLANK` → `FILL_IN_THE_BLANK`
- 题目过滤：`FILL_BLANK` → `FILL_IN_THE_BLANK`

### 3. 后端数据处理

**DeepSeekService.java** 中的选项处理逻辑：

```java
// 处理选项 - 从Option对象转换为字符串列表
if (questionNode.has("options") && questionNode.get("options").isArray()) {
    List<String> optionStrings = new ArrayList<>();
    for (JsonNode optionNode : questionNode.get("options")) {
        String key = optionNode.get("key").asText();
        String content = optionNode.get("content").asText();
        optionStrings.add(key + ". " + content);
    }
    question.setOptions(optionStrings);
}
```

这样处理后，选项格式为：
- "A. 选项内容"
- "B. 选项内容"
- "C. 选项内容"
- "D. 选项内容"

## 修复效果

### 修复前

```
•

•
```

### 修复后
```

A. for

```

## 技术细节

### 1. 数据流程

1. **AI生成**：DeepSeek API返回包含 `key` 和 `content` 的选项对象
2. **后端处理**：DeepSeekService将选项转换为字符串列表
3. **前端显示**：直接显示字符串内容

### 2. 题目类型映射

| 前端显示 | 前端值 | 后端枚举 |
|---------|--------|----------|
| 单选题 | SINGLE_CHOICE | SINGLE_CHOICE |
| 多选题 | MULTIPLE_CHOICE | MULTIPLE_CHOICE |
| 填空题 | FILL_IN_THE_BLANK | FILL_IN_THE_BLANK |
| 简答题 | SHORT_ANSWER | SHORT_ANSWER |

### 3. 选项渲染逻辑

```vue
<div v-if="question.type === 'SINGLE_CHOICE' || question.type === 'MULTIPLE_CHOICE'" class="preview-options">
  <div v-for="(option, optionIndex) in question.options" :key="optionIndex" class="preview-option">
    {{ option }}
  </div>
</div>
```
