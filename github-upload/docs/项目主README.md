# 教务题库管理系统

这是一个完整的教务题库管理系统，支持以下功能：
- 手动录入题库
- 从Excel自动导入题库
- 依照题目类型自动出题
- 集成DeepSeek AI接口辅助教师出题
- 支持语文、数学、英语三门学科

## 技术栈
- 前端：Vue.js + Element Plus
- 后端：Spring Boot 3.3（Node.js 后端已下线）
- 数据库：MySQL
- AI接口：DeepSeek API
