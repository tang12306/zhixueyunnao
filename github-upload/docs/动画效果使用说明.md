# 前端动画效果使用说明

## 概述

本项目已成功集成了多种现代化的动画效果库和自定义动画组件，为教务题库管理系统提供了丰富的视觉体验和交互效果。

## 已安装的动画库

### 1. 核心动画库
- **animate.css** - CSS 动画库，提供丰富的预设动画效果
- **@vueuse/motion** - Vue 3 的现代动画库，支持手势和动画
- **AOS (Animate On Scroll)** - 滚动触发动画库
- **NProgress** - 页面加载进度条
- **@iconify/vue** - 丰富的图标库
- **vue-loading-overlay** - 加载遮罩层组件

## 动画效果实现

### 1. 全局动画配置

#### 主入口文件 (main.js)
```javascript
// 动画库导入和配置
import 'animate.css'
import { MotionPlugin } from '@vueuse/motion'
import AOS from 'aos'
import 'aos/dist/aos.css'
import NProgress from 'nprogress'
import 'nprogress/nprogress.css'

// NProgress 配置
NProgress.configure({
  easing: 'ease',
  speed: 500,
  showSpinner: false,
  trickleSpeed: 200,
  minimum: 0.3
})

// AOS 初始化
AOS.init({
  duration: 800,
  easing: 'ease-in-out',
  once: true,
  mirror: false
})
```

### 2. 页面切换动画

#### 路由进度条 (router/index.js)
- 页面切换时自动显示进度条
- 使用 NProgress 提供流畅的加载体验

```javascript
// 路由前置守卫
router.beforeEach((to, from, next) => {
  NProgress.start() // 开始进度条
  // ... 其他逻辑
})

// 路由后置守卫
router.afterEach(() => {
  NProgress.done() // 完成进度条
})
```

## 动画工具函数

#### 主要功能

2. **数字滚动动画** - `animateNumber()` 函数

## 性能优化建议

### 1. 动画性能
- 使用 `transform` 和 `opacity` 属性进行动画
- 避免动画 `width`、`height` 等会触发重排的属性
- 使用 `will-change` 属性优化动画性能

### 2. 减少动画数量
- 在移动设备上可以减少或禁用某些动画
- 使用 `prefers-reduced-motion` 媒体查询尊重用户偏好

### 3. 懒加载动画
- 使用 AOS 的 `once: true` 配置避免重复动画
- 合理设置动画延迟，避免同时触发过多动画

## 浏览器兼容性

### 支持的浏览器
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

### 降级处理
- 对于不支持的浏览器，动画会自动降级为静态效果
- 使用 CSS `@supports` 查询进行功能检测

## 自定义动画

### 添加新动画
1. 在 `utils/animations.js` 中定义动画配置
2. 在组件中使用 `v-motion` 指令
3. 或者在 CSS 中定义 `@keyframes` 动画

### 示例：自定义弹跳动画
```css
@keyframes customBounce {
  0%, 20%, 60%, 100% { transform: translateY(0); }
  40% { transform: translateY(-30px); }
  80% { transform: translateY(-15px); }
}

.custom-bounce {
  animation: customBounce 1s ease-in-out;
}
```
