# AI功能修复测试指南

## 修复内容总结

### 1. 修复了AI一键出卷不会真正向DeepSeek发送请求的问题
- **问题**：系统在API调用失败时返回模拟数据，用户无法知道真实的API调用状态
- **修复**：移除模拟数据返回逻辑，API调用失败时直接抛出异常，并提供详细的错误信息

### 2. 修复了AI一键出题保存时不会自动给出题目类型的问题
- **问题**：AI生成的题目可能缺少类型信息，保存时题目类型丢失
- **修复**：确保在AI服务和前端都正确设置和传递题目类型信息

## 测试步骤

### 测试1：AI一键出题功能

#### 步骤1：访问AI智能出题页面
1. 打开浏览器访问：`http://localhost:8083/auto-quiz/ai-create`
2. 使用教师账号登录（用户名：demo.teacher，密码：DemoTeacher123!）

#### 步骤2：填写出题参数
1. 选择学科：例如"数学"
2. 选择题型：例如"单选题"
3. 选择难度：例如"中等"
4. 输入题目数量：例如"3"
5. 输入自定义提示词（可选）

#### 步骤3：开始智能出题
1. 点击"开始智能出题"按钮
2. 观察加载状态和进度
3. 检查后端日志是否显示真实的API调用

#### 步骤4：检查生成的题目
1. 查看生成的题目是否包含正确的题型信息
2. 检查题目类型字段是否为下拉选择框（而不是文本输入框）
3. 验证题目类型是否与选择的类型一致

#### 步骤5：保存题目
1. 编辑题目内容（可选）
2. 点击"保存所有题目"按钮
3. 检查保存成功的提示
4. 验证题目是否正确保存到数据库

### 测试2：AI一键出卷功能

#### 步骤1：访问AI一键出卷页面
1. 打开浏览器访问：`http://localhost:8083/auto-quiz/exam-generation`
2. 确保已登录教师账号

#### 步骤2：填写考试信息
1. 输入考试名称：例如"数学期中考试"
2. 选择学科：例如"数学"
3. 设置考试时长：例如"120分钟"
4. 设置总分：例如"100分"
5. 配置题型分布（单选题、多选题等）

#### 步骤3：开始生成试卷
1. 点击"开始生成试卷"按钮
2. 观察生成进度
3. 检查后端日志是否显示真实的API调用

#### 步骤4：检查生成的试卷
1. 验证试卷是否包含正确数量和类型的题目
2. 检查题目分值是否正确
3. 验证试卷总分是否符合设置

## 后端日志检查要点

### 成功的API调用日志应该包含：
```
INFO com._1.service.DeepSeekService : 发送AI生成请求，提示词: [提示词内容]
INFO com._1.service.DeepSeekService : 成功从DeepSeek API获取响应，长度为: [响应长度] 字符
```

### 如果API调用失败，应该看到：
```
ERROR com._1.service.DeepSeekService : 调用AI生成内容失败: [错误类型] - [错误信息]
ERROR com._1.service.DeepSeekService : DeepSeek API密钥未配置或为空
或
ERROR com._1.service.DeepSeekService : DeepSeek API URL未配置或为空
```

### 题目类型设置日志：
```
DEBUG com._1.service.impl.AIServiceImpl : 为题目设置类型: [题型]
```

## 预期结果

### 修复前的问题：
1. ❌ API调用失败时返回模拟数据，用户无法知道真实状态
2. ❌ 生成的题目缺少类型信息或类型信息丢失

3. ✅ 题目类型字段为下拉选择框，便于编辑
4. ✅ 保存题目时正确传递和存储类型信息
5. ✅ 后端日志显示详细的API调用和处理过程

## 故障排除

### 如果API调用仍然失败：
1. 检查`application.properties`中的API密钥配置
2. 验证网络连接是否正常
3. 检查DeepSeek API服务状态
4. 查看详细的错误日志

### 如果题目类型仍然丢失：
1. 检查前端表单是否正确选择了题型
2. 验证浏览器控制台是否有JavaScript错误
3. 检查后端日志中的题目处理过程
4. 确认数据库中题目类型字段的存储情况

## 配置检查

### 确保以下配置正确：
```properties
# application.properties
deepseek.api.url=https://api.deepseek.com/chat/completions
deepseek.api.key=${DEEPSEEK_API_KEY:}
```

INFO com._1.service.DeepSeekService : 成功连接到 api.deepseek.com:443
