# 如何添加江苏师范大学校徽

## 📁 文件位置

请将校徽文件放置在以下目录：
```
教务题库系统/frontend/src/assets/
```

## 🖼️ 支持的文件格式和命名

### 主要校徽文件
- **logo.png** (推荐) - 主要校徽，用于登录页面和Dashboard
- **logo.svg** (备选) - 矢量格式，缩放不失真
- **logo.jpg** (备选) - JPEG格式

### 可选的校徽文件
- **logo-small.png** - 小尺寸校徽，用于侧边栏收缩时显示
- **logo-white.png** - 白色版本校徽，用于深色背景

## 📏 推荐尺寸

- **登录页面校徽**: 60px 高度，宽度自适应
- **Dashboard页面校徽**: 80px 高度，宽度自适应  
- **侧边栏校徽**: 40px 高度，宽度自适应
- **侧边栏小校徽**: 32px × 32px

## 🎨 设计要求

1. **背景**: 建议使用透明背景的PNG格式
2. **清晰度**: 确保在不同尺寸下都清晰可见
3. **品牌规范**: 遵循江苏师范大学官方品牌使用规范
4. **颜色**: 保持校徽原有颜色，系统会自动适配

## 📍 校徽显示位置

### 1. 登录页面
- 位置：系统标题左侧
- 尺寸：60px 高度
- 效果：带有脉冲动画效果

### 2. 主页面侧边栏
- 位置：Logo区域
- 正常状态：40px 高度 + "智慧教学云脑" 文字
- 收缩状态：32px × 32px 或显示 "云脑" 文字

### 3. Dashboard页面
- 位置：页面头部区域
- 尺寸：80px 高度
- 效果：带有阴影效果

## 🔧 添加步骤

1. **准备校徽文件**
   - 确保文件格式为 PNG、SVG 或 JPG
   - 建议使用透明背景的 PNG 格式
   - 文件大小建议控制在 500KB 以内

2. **重命名文件**
   - 将主校徽文件重命名为 `logo.png`
   - 如有小尺寸版本，重命名为 `logo-small.png`

3. **放置文件**
   - 将文件复制到 `教务题库系统/frontend/src/assets/` 目录下

4. **验证显示**
   - 重新启动前端服务（如果正在运行）
   - 访问登录页面和Dashboard页面
   - 确认校徽正确显示

## 🚨 注意事项

- 如果校徽文件不存在或加载失败，系统会自动显示默认图标
- 校徽文件名必须严格按照要求命名（区分大小写）
- 建议使用高质量的校徽图片以确保显示效果
- 如需修改校徽尺寸，可以联系开发人员调整CSS样式

## 🔄 故障排除

### 校徽不显示
1. 检查文件名是否正确（logo.png）
2. 检查文件是否放在正确目录
3. 检查文件格式是否支持
4. 尝试刷新浏览器缓存

### 校徽显示模糊
1. 使用更高分辨率的图片
2. 建议使用SVG矢量格式
3. 确保图片质量足够高

### 校徽尺寸不合适
1. 使用图片编辑软件调整尺寸
2. 或联系开发人员调整CSS样式

## 📞 技术支持

如果在添加校徽过程中遇到问题，请联系系统开发人员获取技术支持。
