# 系统启动问题终极解决方案

## 🎯 问题根源分析

### 主要问题
1. **端口配置不一致** - 前端配置文件设置8083，实际运行8084
2. **CORS配置滞后** - 后端CORS配置没有及时更新
3. **手动启动繁琐** - 每次都需要手动启动多个服务
4. **缺乏状态检查** - 无法快速判断服务是否正常

### 根本原因
- 配置文件与实际运行环境不匹配
- 缺乏统一的启动和管理机制
- 没有自动化的服务检查和恢复

## ✅ 终极解决方案

### 1. 统一端口配置

#### 前端端口配置 (vue.config.js)
```javascript
devServer: {
  port: 8084, // 统一使用8084端口
  host: 'localhost',
  open: false,
  hot: true,
  historyApiFallback: true,
  allowedHosts: 'all'
}
```

## 🔍 故障排除

### 常见问题及解决方案

#### 1. 端口被占用
```bash
# 检查端口占用
netstat -ano | findstr :8084
netstat -ano | findstr :8080

# 终止占用进程
taskkill /f /pid [进程ID]
```

#### 2. 服务启动失败
```bash
# 运行状态检查脚本
检查服务状态.bat
```

#### 3. 前端连接后端失败
- 确认后端服务已启动 (8080端口)
- 确认CORS配置包含8084端口
- 清除浏览器缓存

#### 4. 登录失败
- 使用正确账号: teacher/teacher
- 清除localStorage: `localStorage.clear()`
- 检查网络连接
