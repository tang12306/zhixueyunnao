# 🚀 启动脚本使用说明 v2.0

## 📁 脚本文件说明

### 主要脚本

#### 1. `start.bat` - 增强版主启动脚本 ⭐
- **功能**: 智能启动整个系统的所有服务
- **新特性**:
  - ✅ 分步骤启动，实时状态反馈
  - ✅ 智能等待服务就绪
  - ✅ 详细的错误诊断和日志记录
  - ✅ 服务健康检查
  - ✅ 自动创建默认管理员账户
  - ✅ UTF-8 编码支持，避免中文乱码
  - ✅ 启动日志记录到 startup.log
- **使用**: 双击运行即可

#### 2. `stop.bat` - 系统停止脚本
- **功能**: 优雅停止所有正在运行的服务
- **特点**:
  - ✅ 按顺序停止所有应用服务
  - ✅ 停止数据库容器 (Docker)
  - ✅ 清理进程和端口占用
  - ✅ 验证停止结果
  - ✅ 记录停止日志
- **使用**: 双击运行即可

#### 3. `diagnose.bat` - 系统诊断工具 🔍
- **功能**: 全面的系统健康检查
- **特点**:
  - ✅ 环境检查 (Java, Maven, Docker)
  - ✅ 端口占用状态检查
  - ✅ Docker 容器状态检查
  - ✅ 项目结构完整性检查
  - ✅ 配置文件检查
  - ✅ 服务连通性测试
  - ✅ 进程信息显示
- **使用**: 遇到问题时运行此脚本进行诊断

## 🔧 启动流程详解

### 增强版启动脚本执行步骤

1. **[1/8] 环境检查**
   - ✅ 检查 Java 环境 (需要 Java 17+)
   - ✅ 验证 Java 版本和配置
   - ✅ 记录环境信息到日志

2. **[2/8] Maven 配置检查**
   - ✅ 检测系统 Maven 或使用 Maven Wrapper
   - ✅ 验证 Maven 可执行性
   - ✅ 自动选择最佳 Maven 配置

3. **[3/8] 进程清理**
   - ✅ 智能停止现有 Java 进程
   - ✅ 清理 Node.js 进程
   - ✅ 避免端口冲突

4. **[4/8] Docker 环境检查**
   - ✅ 验证 Docker 安装和运行状态
   - ✅ 检查 Docker Desktop 可用性

5. **[5/8] 数据库服务启动**
   - ✅ 启动 Docker Compose
   - ✅ MySQL 容器 (端口 3306)
   - ✅ MongoDB 容器 (端口 27017)
   - ✅ 等待数据库初始化完成
   - ✅ 验证数据库连接

6. **[6/8] 后端服务启动**
   - ✅ 启动 Node.js 后端 (端口 5000)
   - ✅ 启动 Spring Boot 后端 (端口 8080)
   - ✅ 验证项目文件存在
   - ✅ 分别在独立窗口启动

7. **[7/8] 前端服务启动**
   - ✅ 启动 Vue.js 前端 (端口 8083)
   - ✅ 验证前端项目完整性

8. **[8/8] 服务就绪检查**
   - ✅ 智能等待所有服务启动完成
   - ✅ 健康检查每个服务端点
   - ✅ 最多等待 60 秒，超时提醒
   - ✅ 创建默认管理员用户
   - ✅ 自动打开浏览器

## ⚠️ 常见问题与解决方案

### 1. 端口被占用
**问题**: 启动时提示端口被占用
**解决方案**:
- 运行 `清理端口占用.bat`
- 或重启计算机
- 主启动脚本已内置端口清理功能

### 2. Java 环境问题
**问题**: Spring Boot 无法启动
**解决方案**:
- 确保已安装 Java 17 或更高版本
- 检查 JAVA_HOME 环境变量
- 重启命令提示符

### 3. Docker 服务未启动
**问题**: 数据库容器启动失败
**解决方案**:
- 确保 Docker Desktop 正在运行
- 检查 Docker 服务状态
- 重启 Docker Desktop

### 4. 网络连接问题
**问题**: 无法访问外部 API
**解决方案**:
- 检查网络连接
- 确认防火墙设置
- 检查代理配置

## 📋 系统要求

### 必需软件
- ✅ **Java 17+**: Spring Boot 运行环境
- ✅ **Node.js 16+**: 前后端运行环境
- ✅ **Docker Desktop**: 数据库容器
- ✅ **Git**: 代码管理 (可选)

### 系统配置
- **操作系统**: Windows 10/11
- **内存**: 建议 8GB 以上
- **磁盘空间**: 建议 5GB 以上可用空间
- **网络**: 需要互联网连接 (用于 AI 功能)

## 🎯 端口使用说明

### 应用端口
- **5000**: Node.js 后端 API
- **8080**: Spring Boot 后端 API  
- **8083**: Vue.js 前端界面

### 数据库端口
- **3306**: MySQL 数据库
- **27017**: MongoDB 数据库

### 开发端口 (可能占用)
- **3000**: 开发服务器
- **35729**: LiveReload 服务

## 🔄 重启系统

### 完全重启步骤
1. 运行 `停止所有服务.bat`
2. 等待所有服务停止
3. 运行 `一键启动项目.bat`
4. 等待所有服务启动完成

### 快速重启 (仅应用)
1. 在各个服务窗口按 `Ctrl+C`
2. 运行 `清理端口占用.bat` (如需要)
3. 运行 `一键启动项目.bat`

## 📞 故障排除

### 日志查看
- **Node.js**: 查看 Node.js Backend 窗口
- **Spring Boot**: 查看 Spring Boot Backend 窗口
- **Vue.js**: 查看 Vue.js Frontend 窗口
- **Docker**: 运行 `docker-compose logs`

### 常用命令
```bash
# 查看端口占用
netstat -ano | findstr :8080

# 查看 Docker 容器状态
docker ps

# 查看 Docker 日志
docker-compose logs

# 重建 Docker 容器
docker-compose down
docker-compose up -d --build
```
